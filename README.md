
# Библиотека: Электронный каталог книг
Библиотека — это простое десктопное приложение (WPF + C#) с базой данных для управления книжным фондом и выдачей литературы. Приложение позволяет пользователям просматривать каталог, брать книги в долг и управлять своим профилем. Администраторы могут видеть всю историю выдачи и добавлять новые книги.
## Визуальная демонстрация
В приложении реализован простой и понятный интерфейс:

Каталог книг с возможностью добавления их для выдачи.
История выданных книг (личная или общая).
Профиль пользователя с управлением контактными данными.
## Установка (Installation)
Клонируйте репозиторий:git clone https://github.com/midowwx/Biblioteka
cd library

Установите необходимые зависимости через NuGet Package Manager Visual Studio или используйте консоль разработчика:dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet restore

Создайте базу данных. Для этого откройте файл App.xaml.cs и выполните миграцию базы данных при первом запуске приложения.
## Использование (Usage)

### Регистрация нового читателя

Запустите приложение и нажмите кнопку регистрации. Заполните поля Имя, Фамилия, Логин и Пароль. После успешной регистрации вы попадёте на страницу входа. Войдите в приложения введя свой логин и пароль.

### Работа с приложением

На главной странице доступны три вкладки:

Каталог: просмотр всех доступных книг. Обычные пользователи могут взять книгу из списка. Администратор может добавить новую книгу.
Выдачи: история взятых вами книг. Администратор видит все выдачи читателей.
Профиль: управление вашими личными данными. Вы можете указать Email и номер телефона.

## Данные (Data)

Приложение использует локальную SQL Server Express базу данных (по умолчанию LocalDB) через Entity Framework Core. 

База данных содержит следующие таблицы:

Readers: Пользователи (ID, имя, фамилия, логин, пароль, роль).
Books: Каталог книг (ID, название, автор, год издания, фото).
Loans: Журнал выдач (ID книги, ID читателя, дата).
Authors: Авторы книг(ID, имя, фамилия, дата рождения, дата смерти)
Categories: категории книг (ID, название категории)

Роль (Rol) определяет права доступа:

1: обычный пользователь (может брать книги и редактировать профиль).
2: администратор (видит все выдачи и может добавлять книги).
